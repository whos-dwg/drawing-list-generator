# 操作指南

[返回 README](../README.md)

## 準備資料

使用可正常讀取的 DWG 與 Excel 範本副本。圖框須為紙空間 Layout 中直接插入的 `A1_TITLE_EN` 圖塊；圖號屬性為 `DWG_NUMBER`，圖名屬性為 `DRAWING_TITLE_1` 至 `DRAWING_TITLE_4`。

預設 Excel 工作表名稱為 `Drawing List`，輸出從 A9:D9 起算。範本、客戶圖紙與外部元件須自行準備。

## 1. 選擇檔案

1. 在 DWG 區域選取一個或多個檔案。
2. 要加入其他資料夾的 DWG，按 **ADD DWG**。
3. 在 XLS 區域選取 `.xls` 或 `.xlsx` 範本。
4. 設定 **DRAWING SIZE**；此值套用至本次所有圖紙列，預設為 A1。
5. 設定 **CURRENT BATCH**；一般輸出勾選時寫入 `v`，取消時寫入空字串。

ADD DWG 依檔名、大小與最後修改時間避免重複加入。使用 **CLEAR** 可清除目前選檔與掃描結果；它不會刪除磁碟上的掃描快取。

## 2. 掃描

按 **SCAN DRAWINGS**。程式依序處理各 DWG，顯示 SCANNED 或 CACHED 計數，接著彙整 Layout。

掃描快取以掃描器版本字串與 DWG 檔案內容產生索引；相同檔名不代表相同快取。修改 DWG 內容後會使用另一個索引。

## 3. 檢查分類

| 畫面狀態 | 意義 | 操作 |
| --- | --- | --- |
| 綠色 AUTO | 程式從圖名或圖號找到分類依據 | 確認結果是否符合專案慣例 |
| 藍色 MANUAL | 使用者已指定分類 | 可按 AUTO 回到自動判斷 |
| 琥珀色 REVIEW | 無法分類，或圖名與圖號分類衝突 | 選擇分類，或明確按 CONFIRM OTHER |

自動分類的 high／medium 表示程式找到的證據組合，不是統計準確率。High 是圖名與圖號一致，medium 是其中一種來源可判斷。

**VIEW TITLE BLOCK DATA** 可查看原始圖框屬性。介面目前可調整分類與納入狀態，無法直接編輯掃描出的圖號與圖名；來源資料錯誤應修正 DWG 後重新掃描。

## 4. 處理檢查項目

| 代碼 | 影響與處理方式 |
| --- | --- |
| `UNCONFIRMED_CLASSIFICATION` | 阻擋產生；選擇分類或 CONFIRM OTHER |
| `DUPLICATE_DWG_NUMBER` | 阻擋產生；點擊問題跳至對應列，修正 DWG 或取消重複圖紙的納入 |
| `MISSING_DWG_NUMBER` | 阻擋產生；補齊來源 DWG 圖號 |
| `MISSING_TITLE_BLOCK` | 無圖框的 Layout 預設不納入；若手動納入則成為阻擋項目 |
| `MULTIPLE_TITLE_BLOCKS` | 顯示警告；掃描器目前只讀第一個符合圖框，應檢查是否讀到正確資料 |
| `MISSING_DRAWING_TITLE` | 顯示警告；必要時補齊圖名後重新掃描 |
| `EMPTY_ATTRIBUTE:…` | 可能出現在列 STATUS；為避免重複訊息，不逐一列入可操作警告清單 |

被排除的 Layout 仍可能顯示警告，但不會納入重複圖號或分類確認的輸出檢查。

## 5. 預覽與產生

Excel write preview 顯示分類標題、空白列、圖紙列及目標儲存格。先核對工作表、列數、圖號順序與標記，再按 **GENERATE DRAWING LIST**。

程式會下載 `Drawing List.xls` 或 `Drawing List.xlsx`，依輸入範本副檔名決定。它將範本複製到暫存區處理，不以輸入路徑覆寫原始範本；下載時的同名檔案處理由瀏覽器決定。

分類標題和空白列也會占用列數。預設 A9 為第一個輸出位置，啟用自動分類時，第一筆圖紙通常從 A10 開始。

## XLS 修訂模式

當 `.xls` 範本起始區域已有符合規則的圖號，且保留 Current Batch 欄位時，寫入器會進入修訂模式：

- 讀取既有圖紙，合併本次圖紙；本次未提供的既有圖紙仍會保留。
- 以圖號比對，更新本次圖名與尺寸，再重整分類與排序。
- 保留既有歷史標記，從設定的批次欄向右尋找未占用的欄位，為本次圖紙寫入 `v`。

此路徑含 A/B/C 與 A:L 固定欄位假設，最多讀取至第 2000 列；既有圖紙之後連續五列沒有清單值時會提早停止。歷史標記讀取範圍與批次搜尋也有限制，請先檢查範本是否符合。

**CURRENT BATCH 取消勾選目前無法停止 XLS 修訂模式的批次標記**，因為該路徑直接寫入 `v`。網頁預覽只顯示本次掃描資料，未展示修訂合併後的完整清單。完成後請在 Excel 中核對既有圖紙、歷史批次與新批次。

`.xlsx` 使用另一個逐列寫入流程，沒有上述 XLS 修訂合併行為。

## 工作階段與紀錄

目前管理設定與人工分類保留在頁面記憶體中；重新整理後需重新設定與選檔。頁面每 30 秒送出本機心跳，服務超過約兩分鐘未收到請求時會嘗試關閉，之後需重新啟動。

掃描失敗時，記下 Diagnostic ID，再從 ADMIN SETTINGS 開啟診斷資料夾。回報前移除敏感內容，參見[疑難排解](TROUBLESHOOTING.zh-TW.md)。
