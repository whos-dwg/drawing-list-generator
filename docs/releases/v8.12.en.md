# Drawing List Generator v8.12 — Silent Layout Field Fix

Layout-dependent drawing-number corrections remain automatic and no longer appear as user-facing warnings. Duplicate numbers, missing required data, and classification conflicts still require review.

## Changes

- Remove the warning associated with automatic layout-field drawing-number corrections.
- Retain actionable validation and classification checks.

## Download

Use **DrawingList-Generator-v8.12-Windows-Portable.zip**. Extract it fully and double-click `DrawingList.exe`, keeping `app` and `runtime` together.

The prepared asset removes scan caches and PDB debug symbols from the supplied v8.12 package and adds MIT and Node.js license texts. Application source, the launcher, and scanner DLLs retain their supplied contents. Verify the asset against `SHA256SUMS.txt`.

Windows, local AutoCAD, and desktop Microsoft Excel are required. The original notes identify AutoCAD 2021 as validated; included 2018 and 2026 scanners await device testing. XLS export also requires ACE OLEDB 12.0. The XLSX worker currently uses a fixed Office16 Excel path.

## Upgrade and validation

Extract to a new folder and rescan your DWGs using your Excel template. Recheck session-specific worksheet and output settings.

All 9 existing core tests passed under Node.js v24.18.0 on 2026-10-30. This pass did not revalidate AutoCAD scanning, Excel export, or launcher integration. See the [README](../../README.en.md) for template and revision-mode limitations.
