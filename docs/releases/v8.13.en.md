# Drawing List Generator v8.13 — Configurable CAD Input

Configure exact title-block names and source attribute mappings in **ADMIN SETTINGS → CAD INPUT**. Custom blocks and drawing-number tags use the AutoCAD 2021 scanner.

## Added

- Multiple comma-separated block names, matched without regard to case.
- Source mappings for drawing number and Title 1–4; unused title mappings may be blank.
- Local CAD input persistence, SAVE INPUT SETTINGS, and RESET TO DEFAULT.
- DISCOVERED BLOCKS with paper-space block names, counts, and tags.
- Constant-attribute reading and retained raw attributes for additional Excel tokens.
- Preview remapping without a CAD rescan when only attribute tags change.
- Export protection when selected block names differ from those used for the scan.
- CAD input settings in scan-cache keys and validation for an empty drawing selection.

## Download and upgrade

Download **DrawingList-Generator-v8.13-Windows-Portable.zip**, extract it fully, and double-click `DrawingList.exe`. Keep `app` and `runtime` together.

When upgrading from v8.12, extract into a new folder and configure CAD INPUT. Defaults remain `A1_TITLE_EN` with the original standard tags. CAD input settings persist in `app/local-settings.json`; Excel output settings and manual classifications remain session-specific.

For example, map `CONSULTANT_FRAME` / `SHEET_ID` to drawing number, `PROJECT` to Title 1, `TITLE_EN` to Title 3, `TITLE_CN` to Title 4, and leave Title 2 blank. Title output order remains 1 → 3 → 2 → 4.

## Validation and requirements

All **15 unit tests passed** on 2026-11-02 under Node.js v24.22.1, including 6 new CAD input tests. The included AutoCAD/Excel integration script was not run during this publication pass. Scanner DLLs and the launcher were retained, not rebuilt or executed.

The custom-block/custom-number-tag worker path requires AutoCAD 2021. The 2018 and 2026 scanners retain their supplied contents and await device testing. Windows, local AutoCAD, and desktop Excel are required; XLS also needs ACE OLEDB 12.0.

The prepared asset excludes PDB symbols and local state and adds MIT and Node.js licenses. Verify it against **SHA256SUMS.txt**.
