# Drawing List Generator v8.12 — Silent Layout Field Fix

本版讓 Layout 圖號欄位修正繼續自動執行，並移除這類修正的使用者警告。掃描時，符合規則的 Model／CTAB 快取圖號會依目前處理的 Layout 正規化；重複圖號、缺漏資料及分類衝突仍須處理。

## 本次變更

- Layout 欄位圖號修正不再出現在使用者警告清單。
- 保留需要人工處理的分類確認、重複圖號與必要欄位檢查。

## 下載與安裝

下載本 Release 的 **DrawingList-Generator-v8.12-Windows-Portable.zip**，完整解壓縮後雙擊 `DrawingList.exe`。請保留 `app` 與 `runtime` 資料夾。

本次發布包由提供的 v8.12 ZIP 整理而成，已移除掃描快取與 PDB 除錯符號，補入 MIT 與隨附 Node.js 的授權文字；應用程式原始碼、啟動器與掃描 DLL 保持來源內容。SHA-256 見附件 `SHA256SUMS.txt`。

## 環境與相容性

- Windows、本機 AutoCAD、桌面版 Microsoft Excel。
- AutoCAD 2021 是原發行文件的已驗證目標；2018／2026 掃描 DLL 已包含，仍待裝置測試。
- `.xls` 額外需要 `Microsoft.ACE.OLEDB.12.0`。
- `.xlsx` 腳本目前使用固定的 Office16 Excel 執行路徑。

## 更新方式

將新版解壓縮到新資料夾，使用原有 DWG 與 Excel 範本重新掃描。管理設定目前只保留在頁面工作階段，請重新確認工作表與輸出起點。

`.xls` 修訂模式會合併既有圖紙與此次圖紙；請以範本副本檢查歷史批次、合併儲存格與排版。完整限制見 README。

## 驗證狀態

2026-10-30 以 Node.js v24.18.0 重跑來源中的 9 項核心測試，全部通過。此為分類、分組及 Layout 圖號正規化測試；本次整理未重新執行 AutoCAD 掃描、Excel 匯出或啟動器整合測試。
