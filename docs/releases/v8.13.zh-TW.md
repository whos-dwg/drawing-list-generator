# Drawing List Generator v8.13 — Configurable CAD Input

v8.13 可在 ADMIN SETTINGS 的 **CAD INPUT / 圖框與屬性** 指定圖塊全名與來源屬性，不必為每個圖框名稱修改掃描器。自訂圖框與圖號標籤的掃描路徑使用 AutoCAD 2021。

## 新增內容

- 支援以逗號列出多個圖塊全名，完整名稱比對不分大小寫。
- 把來源屬性映射到 Drawing number、Title 1–4；圖名欄位可留空，圖號標籤必填。
- **SAVE INPUT SETTINGS** 保存 CAD 輸入設定，下次啟動還原；**RESET TO DEFAULT** 可回復預設。
- **DISCOVERED BLOCKS** 顯示紙空間中的圖塊名稱、數量與屬性，點選名稱可帶入設定。
- 讀取所選圖框的常數與參考屬性，保留原始標籤供 Excel 的 `{TAG_NAME}` Token 使用。
- 只改屬性映射可從既有原始資料更新預覽；改圖塊名稱後須重掃，避免匯出過期結果。
- 快取索引納入 CAD 輸入設定，新增沒有納入圖紙與圖框設定不符的匯出檢查。

## 使用範例

1. 開啟 ADMIN SETTINGS → CAD INPUT。
2. 圖塊名稱輸入 `CONSULTANT_FRAME`。
3. Drawing number 設為 `SHEET_ID`；Title 1 設為 `PROJECT`，Title 2 留空，Title 3 設為 `TITLE_EN`，Title 4 設為 `TITLE_CN`。
4. 按 SAVE INPUT SETTINGS，再按 SCAN DRAWINGS。

圖名仍依 1 → 3 → 2 → 4 組合。每個 Layout 找到多個符合圖框時，仍顯示 MULTIPLE_TITLE_BLOCKS 並讀取第一個，應自行核對。

## 安裝與更新

下載本 Release 的 **DrawingList-Generator-v8.13-Windows-Portable.zip**，完整解壓縮後雙擊 `DrawingList.exe`，保留 `app` 與 `runtime`。

從 v8.12 更新時，將新版解壓縮到新資料夾，再設定需要的 CAD INPUT。預設仍為 `A1_TITLE_EN` 與標準圖號／圖名屬性。CAD 輸入設定保存在 `app/local-settings.json`；Excel 輸出位置、公式與人工分類仍為頁面工作階段設定。

本次未執行隨附的 AutoCAD／Excel 整合測試，亦未重建 DLL 或執行免安裝啟動器。AutoCAD 2018／2026 的 DLL 保留原包版本；自訂圖框或圖號標籤會由工作程序限制使用 2021。紙空間直接圖塊、巢狀圖塊與外部參考的範圍限制仍適用。

Windows、本機 AutoCAD 與桌面版 Excel 仍為必要環境；XLS 另需 ACE OLEDB 12.0，XLSX 腳本仍有固定 Office16 路徑。
